## 🧠 Key Takeaways (updated as I go)

- **Semantic HTML** isn't about looks — it's about meaning: accessibility, SEO,
  and maintainability all depend on it.
- **`id` vs `class`**: `id` is unique per page (styling hook / JS / anchors),
  `class` is reusable across elements.
- Always write clean attribute syntax: `attr="value"`, no stray spaces.
- Every `<img>` needs a *descriptive* `alt`, not a placeholder word.
